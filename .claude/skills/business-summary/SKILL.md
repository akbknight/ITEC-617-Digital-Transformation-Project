# Business Value Summary Generator

## Activation
When the user invokes /business-summary, OR when you generate any Python/R code, data analysis, quantitative model, or complex research output, automatically run this skill to produce a plain-English Business Value Summary.

## Auto-Trigger Conditions
This skill activates automatically (without the user needing to invoke /business-summary) whenever you:
- Write or explain Python or R code
- Build a financial model, ROI calculation, or sensitivity analysis
- Produce a competitive analysis, market research summary, or technology assessment
- Generate data visualizations or interpret data outputs
- Complete a Gartner Hype Cycle or NASA TRL assessment

**Note**: The `/hospitality-research` and `/tech-validate` commands prompt the student before triggering this skill rather than invoking it automatically. If the student confirms, run this skill once. If they decline, skip it. Do not produce duplicate Business Value Summaries.

In auto-trigger mode (non-prompted), append the Business Value Summary to your response and offer to save it to `documentation/business-summaries/`.

## Context to Read
Before generating a summary, read:
1. `student-workspace/project-brief.md` — for project context
2. `research/active-research.md` — for target company and technology configuration
3. The technical content just produced (code, analysis, research)

## Instructions

### Step 1 — Understand the Technical Content
Identify:
- What was built or analyzed (code, model, research, visualization)
- What technical domain it belongs to (financial modeling, data analysis, technology architecture, market research, etc.)
- What the output means quantitatively or qualitatively

### Step 2 — Translate for a Non-Technical Business Audience
Write as if explaining to a smart colleague who has no technical background but understands business strategy, ROI, and competitive dynamics. Avoid:
- Technical jargon without explanation
- Code snippets or formulas (summarize their purpose and result instead)
- Acronyms without expansion on first use

### Step 3 — Connect to Business Value
Every summary must explicitly connect the technical output to:
- **ROI / Financial Impact**: How does this affect the financial projections or cost-benefit analysis?
- **Strategic Value**: How does this strengthen the DT proposal's competitive positioning or address the core business problem?
- **Risk Implications**: Does this raise new risks or reduce existing ones? Reference the primer/06-risk-management.md framework.
- **Presentation Relevance**: Which slide or section of the 10-minute judge presentation should reflect this finding?

### Step 4 — Assign Team Action Items
Based on team composition (IT Expert, Telecom Specialist, International Business Developer, Financial Analyst):
- Identify which team member should review, validate, or build on each finding
- Assign concrete next steps appropriate to each person's domain

### Step 5 — Save the Summary
Generate a file in `documentation/business-summaries/` with the naming convention:
`YYYY-MM-DD_[topic-slug]_business-summary.md`

Use today's date. Create a slug from the topic (e.g., `roi-model`, `competitor-analysis`, `pricing-algorithm`).

## Behavioral Guidelines
- Always produce the Business Value Summary in addition to (not instead of) the technical output
- Keep summaries concise — the goal is a 2-minute read for a busy teammate
- Use concrete numbers wherever possible; avoid vague language like "significant" or "substantial"
- When auto-triggered, briefly note: "I've also created a Business Value Summary below for your non-technical teammates"
- If the student uses /business-summary without prior technical context, ask: "What technical content would you like me to summarize for your team?"

## Important
This skill bridges the gap between technical work and business communication — critical for a team with mixed backgrounds (IT Expert, Telecom Specialist, International Business Developer, Financial Analyst). Every technical output should have a corresponding business narrative that any team member can read and act on.
